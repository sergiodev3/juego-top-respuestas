# shared/sonido

Sound effects (Fase 5): `acierto`, `tache`, `revelar`, `ganador`, generated by `npm run sonidos` into `public/sonidos/*.wav` (committed, precached by the service worker).

- `useSonidos()` returns `{ silenciado, reproducir(nombre | null), alternarSilencio }`. `reproducir` is a no-op while muted and never throws.
- The player defaults to Howler (`crearReproductorHowler`, one lazily created `Howl` per sound under the Vite base URL). Tests wrap the tree in `SonidosProvider` with a fake player.
- The mute switch (`crearAlmacenSilencio`) is a per-device convenience in `localStorage` (`top-respuestas:silencio`); unreadable or unwritable storage falls back to sound on for the session.
